# Compaction review fixes summary

## 1. `CompactionReport.compaction_block` field — correctness (block-tracking invariant)

**File**: `conversation/compaction.rs`, lines 91–106  
**Category**: Correctness (found by reviewers 1, 2, and structural review)  
**Change**: Replaced `signed: bool` with `compaction_block: Option<CompactionBlock>`.  
`StandardConversation::compact()` now populates `compaction_block: Some(signed)` for
server compaction and `None` for local. In `render_turn`, the dead 16-line match
on `report.strategy` is collapsed to `state.mark_applied(report.compaction_block.clone())`,
preserving the `CompactionState.block` server-vs-local invariant.

**Files**: `compaction.rs` (struct), `standard.rs` (call sites in `compact()` and `render_turn`)

## 2. Chat auto-compaction guard — correctness (threshold=0 regression)

**File**: `conversation/compaction.rs`, `CompactionState::should_compact()`  
**Category**: Correctness (found by reviewer 2)  
**Change**: Added `if self.threshold == 0 { return false; }` as the first check in
`should_compact`. Chat conversations get `threshold = 0` (the on-demand path handles
`/compact`), so without this guard every chat turn past `keep_recent` would
auto-compact. The old `CompactionTrigger::Immediate` variant short-circuited this,
but the deletion of that variant removed the guard.

## 3. `compact()` return type — readability (unreachable `Err` arm)

**File**: `conversation/standard.rs`, `StandardConversation::compact()`  
**Category**: Readability (found by reviewers 1 and 2)  
**Change**: Changed return type from `Result<Option<CompactionReport>, String>` to
`Option<CompactionReport>`. Every error path already logged a warning and returned
`None`; no `Err(...)` was ever constructed. Callers in `render_turn` and `handle_compact`
now use `if let Some(report)` instead of `if let Ok(Some(report))`.

## 4. `unwrap_or("")` guard — robustness

**File**: `conversation/standard.rs`, `compact()` server path  
**Category**: Robustness (found by reviewer 1)  
**Change**: Wrapped the server-compaction block inside `if let Some(model) = &self.compaction_model`,
eliminating `self.compaction_model.as_deref().unwrap_or("")` that forwarded an empty
string to the backend when `compaction_model` was `None`.

## 5. `handle_compact` session lock — performance

**File**: `executor/supervisor.rs`, `handle_compact()`  
**Category**: Performance (found by reviewer 2)  
**Change**: Extracted the lock guard to a block that clones `client`, `model`, and
calls `read_chat_conversation`, then drops the lock before `build_compaction_conversation`
and `conv.compact()` (which may make LLM round-trips). The lock is re-acquired briefly
for `persist_compacted_conversation` only.

## 6. `handle_compact` system prompt comment — readability

**File**: `executor/supervisor.rs`, `handle_compact()`  
**Category**: Readability (found by reviewers 1 and 2)  
**Change**: Fixed the misleading comment ("use the chat gremlin's definition, or fall back to
the default") to accurately state that the default `chat_system_prompt()` is always used —
matching the actual behavior where `create_chat_gremlin` always receives the same prompt.

## 7. `persist_compacted_conversation` noncontiguous artifacts — correctness

**File**: `executor/run.rs`, `persist_compacted_conversation()`  
**Category**: Correctness (found by reviewers 1 and 2)  
**Change**: Replaced the `break`-on-missing sequential loop (`for turn in 2..`) with a bounded
scan (`for turn in 2..1000`) that probes each turn independently — every existing artifact
at turn ≥ 2 is cleared regardless of contiguity. The `break`-on-missing pattern would leave
gaps (e.g. turn 2 deleted but turn 3 remaining) uncleared.

## 8. Extracted `build_compaction_conversation()` helper — coupling/fan-out

**File**: `executor/run.rs` (new function), `executor/supervisor.rs` (call site)  
**Category**: Coupling (found by structural review)  
**Change**: Added `build_compaction_conversation(client, model, is_chat, verbatim_history)`
that calls `build_compaction_parts`, destructures, wraps `Option`s, and constructs
`StandardConversation`. Both `run_agent` (run.rs) and `handle_compact` (supervisor.rs) now
use this single helper instead of duplicating the 5-tuple destructure + Option-wrapping +
constructor call.
